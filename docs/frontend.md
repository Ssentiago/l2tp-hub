# Фронтенд

Документ описывает клиентскую часть на React 19 + TypeScript + Zustand + MUI,
сборку Vite, структуру store, слой вызова команд, компоненты, события и
локализацию.

## Стек и вход

Фронтенд собирается Vite 7, dev-сервер на порту 1420. Точка входа `src/main.tsx`
импортирует `src/core/i18n` (инициализация i18next до рендера) и монтирует `App`
в `#root` в `React.StrictMode`. Роутинга нет, переключение экранов через поле
`viewMode` в store и модальные оверлеи.

Тема: тёмная тема MUI создаётся в `App.tsx`. Глобально отключено выделение текста,
кроме полей ввода.

| Путь | Назначение |

| `src/typing/bindings.ts` | Генерённые TS-типы и обёртки команд (tauri-specta), руками не правится |

## Слой команд (api.ts)

`api.ts` экспортирует пространство имён `api` с группами методов и делегирует в
сгенерированные обёртки `commands` из `src/typing/bindings.ts`. `invoke` из
`@tauri-apps/api/core` импортирует только сгенерённый `bindings.ts`. Группы:
`connections`, `vpn`, `logs`, `sudo`, `labels`, `app`, `system`, `config`, `update`,
`workspaces`.

Все обращения к бэкенду идут только через `api.ts`. Прямые вызовы `invoke` из
компонентов не допускаются.

## Типы (bindings.ts)

Все типы данных фронта генерятся из Rust через specta и tauri-specta: модели ядра
помечены `#[derive(specta::Type)]`, команды атрибутом `#[specta::specta]`. Файл
`src/typing/bindings.ts` перезаписывается генератором, править его руками нельзя.
Ручными остаются только UI-типы: пропсы компонентов, `ConnectionWithStatus` в
`store.ts`, структуры вида.

Генерация запускается командой `npm run gen:types` (cargo-тест `export_bindings`),
вшита в `tauri:dev` и `tauri:build`, а в dev-сборке биндинги перегенерируются при
каждом старте приложения. i64 экспортируется как `number`
(`dangerously_cast_bigints_to_number`). Аргументы команд на проводе идут в
camelCase, сгенерённые обёртки передают ключи сами.

## Store (store.ts)

Zustand store держит состояние интерфейса и данных. Основные группы:

UI: `viewMode` (палитра или управление), `selectedKey` (формат `scope:id`), `query`,
`groupByCompany`.

Данные: `labels`, `workspaces`, `activeWorkspaceId`, `connections` (с полями `status`
и `error`, ошибка подключения структурная: `ConnectError` из биндингов), `appVersion`.

Готовность: `sudoReady`, `helperReady`, `helperStatusText`, `keychainReady`.

Процессы: `connectingId`, `disconnectingId`.

Ключевые действия: `loadConnections`, `saveConnection`, `deleteConnection`,
`connectVpn`, `disconnectVpn`, `switchWorkspace`, `loadLabels`, `saveLabel`,
`deleteLabel`, `checkHelper`, `authenticateSudo`.

`connectVpn` дополнительно проверяет правила режимов на клиенте (full эксклюзивен,
split не совместим с активным full) и оптимистично выставляет статус. Реальная
валидация пересечения подсетей остаётся за бэкендом.

## Слушатель VPN-событий

`initVpnEventListener` подписывается на событие `vpn-status-changed` с полезной
нагрузкой `{ id, status, connected_since, error }`, где `error` — структурная ошибка
`ConnectError` (код, этап, признаки). Подписка идемпотентна, функция
отписки хранится в модульной переменной.

Слушатель игнорирует промежуточные статусы во время отключения и подключения, чтобы
не было мерцания при гонках с троттлингом. Это защита от рассинхрона оптимистичного UI
и реального состояния.

## Ошибки подключения

Код ошибки хранится в `ConnectionWithStatus.error`. Текст, подсказки и действия по
коду разрешаются через ресурсы локализации (`errors.<код>.message`,
`errors.<код>.hints`) в `src/core/connectErrors.ts`, поэтому сообщение не зависит от
формулировок в логах демонов. `ConnectErrorBanner`
(`src/ui/ConnectErrorBanner.tsx`) показывает причину, подсказки и кнопки действий:
повторить подключение, открыть параметры, открыть логи сессии. Панель отображается
в палитре над списком и в карточке подключения в управлении.

## Локализация

i18n построен на `i18next` + `react-i18next`. Ресурсы лежат в `src/locales/ru.json` и
`src/locales/en.json` и подключаются статическим импортом в `src/core/i18n.ts`.
Ключи типизированы через `CustomTypeOptions` (типизация ресурсов в
`src/typing/i18n.d.ts`), динамические ключи типизируются `ParseKeys`.

Выбор языка: сохранённое значение в `localStorage` (ключ `l2tp-hub.lang`), иначе
системный `navigator.language` (начинается с `en` значит английский, иначе русский).
Переключатель языка находится в `Settings`, меняет язык через `i18n.changeLanguage`
и сохраняет выбор. Компоненты используют `useTranslation`, не-React модули
(`display.ts`, `subnet.ts`, `connectErrors.ts`) вызывают `i18n.t` напрямую.

Плюрализация и интерполяция: формы множественного числа через `count`
(`subnet.addresses`, `logDrawer.copied`), простые подстановки через именованные
переменные (`time.*`, `subnet.addressesK`). Динамические строки вроде
относительного времени и валидации подсетей вынесены в ресурсы наравне с лейблами.

Бэкенд отдаёт только английский текст. `user_message` в ядре и статусы, ошибки команд
в `src-tauri` англоязычны и служат техническим fallback и текстом для логов, истории
сессий и поддержки. Пользовательский интерфейс переводится целиком на стороне фронта
по кодам. Английские строки бэка в UI (например статусы `sudo` при русской локали)
до перевода через коды показываются как есть.

## Экраны

Палитра (`PaletteView`). Главный экран быстрого подключения: выбор рабочего
пространства, поиск, строка активного подключения, список с группировкой по компаниям,
подсказки горячих клавиш. Навигация стрелками, Enter подключает, Tab переключает режим.

Управление (`ManageView`). Двухпанельный экран: слева дерево рабочее пространство,
компания, филиал, подключение, справа форма с вкладками параметров, маршрутов и логов.
Создание и редактирование подключений.

Настройки (`Settings`). Экспорт и импорт конфигурации, управление метками, смена
языка, проверка обновлений, опасная зона сброса.

Прочее. `ConnectionLogDrawer` показывает логи сессии, `SudoModal` запрашивает
авторизацию на macOS.

## События от бэкенда

`vpn-status-changed`. Обновляет статус подключения в store.

`app-shown`. Сбрасывает поиск и режим при показе окна (срабатывает от глобального
шортката).

## Вспомогательные модули

`display.ts`. Форматирование заголовка из меток, подсветка совпадений поиска,
относительное и абсолютное время, проверка соответствия запросу. Тексты времени и
формат даты берутся из текущего языка i18n.

`subnet.ts`. Парсинг ввода подсети: CIDR, маска точками, диапазон, сокращение
(`192.168.1` это `/24`), одиночный хост. Нормализация и валидация, сообщения об
ошибках из ресурсов локализации.

## Горячие клавиши

Обрабатываются в `App.tsx`: Escape назад или скрыть, `Cmd+Q` выход, `Cmd+,` настройки,
`Cmd+N` новое подключение, `Cmd+E` управление, `Cmd+D` отключить, `Cmd+Backspace`
удалить, `Cmd+1` через `Cmd+9` переключение рабочих пространств. Глобальный шорткат
`Ctrl+Alt+L` показывает и скрывает окно.
