# Документация L2TP Hub

Здесь собрана подробная документация по подсистемам проекта. Обзор и инструкции для
разработчика лежат в корневом `AGENTS.md`. Этот каталог раскрывает каждую часть
отдельно.

## Оглавление

| Документ | Содержание |
|----------|-----------|
| `architecture.md` | Общая архитектура, модель процессов, IPC, потоки данных |
| `data-model.md` | Модели данных, SQLite, связка ключей, шифрованный backup |
| `core-library.md` | Устройство ядра `l2tp-hub-core` |
| `backend.md` | Tauri-слой `src-tauri`, полный список команд |
| `vpn-lifecycle.md` | Подключение, мульти-подключения, маршруты, режимы туннеля |
| `daemons.md` | Привилегированные демоны helper и route-guardian |
| `frontend.md` | Фронтенд на React, store, компоненты, события |
| `build.md` | Сборка, нативные зависимости, патчи, бандл |

## С чего начать

Для первого знакомства рекомендуется такой порядок: сначала `architecture.md` для
общей картины, затем `data-model.md` чтобы понять, как хранится состояние, затем
`vpn-lifecycle.md` потому что это ядро функциональности. Остальное по необходимости.

## Термины

LAC. L2TP Access Concentrator, секция подключения на стороне клиента. В конфиге
`xl2tpd.conf` каждой подключение соответствует секция `[lac ...]`.

LNS. L2TP Network Server, удалённый VPN-сервер. Поле `lns` в конфиге.

charon. IKE-демон из состава strongSwan, отвечает за IPSec.

xl2tpd. Демон L2TP, поднимает PPP-сессии через системный `pppd`.

pppd. Системный PPP-демон macOS, создаёт интерфейсы `pppN`.

VICI. Интерфейс управления strongSwan, сокет `/var/run/charon.vici`, работает через
`swanctl`.

Split tunnel. Режим, когда через VPN идут только указанные подсети, интернет напрямую.

Full tunnel. Режим, когда весь трафик идёт через VPN (default route перенаправляется).
